
### 9.3 ServiceRequests

`ServiceRequests` provides centralised access to reusable JSON request templates.

The interface defines service-specific enums for organising request templates by their corresponding API.

Templates are stored as JSON resource files under:

`src/test/resources/testdata/requests/`

Each request definition references a corresponding JSON file.

For example:

| Request Definition | Template |
|---|---|
| `CHANGE_TOKEN_OWNER_STATE_REQUEST` | `gateway/change-token-owner-state.json` |
| `GET_OR_CREATE_TOKEN_REQUEST` | `gateway/get-or-create-token.json` |
| `NOTIFICATION_TOKEN_UPDATE_REQUEST` | `gateway/notification-token-update.json` |
| `EMV_IDENTITY_REQUEST` | `auth/emv-identity.json` |
| `GATEWAY_IDENTITY_REQUEST` | `auth/gateway-identity.json` |

`ServiceRequests` supports reading templates as strings, Jackson JSON nodes, or Java objects.

It also provides a `with(Consumer<ObjectNode>)` method for creating modified request payloads without changing the original template.

Detailed examples of JSON template loading, request modification, and payload handling are provided in the **Request & Response Management** chapter.
